# T03 — Evidências de Flexbox e Grid

## Objetivo

Verificar a responsividade dos layouts com Flexbox e Grid, conforme os critérios da tarefa T03.

## Testes realizados

- [x] **Viewport de 320 CSS px:** não apresentou rolagem horizontal.
- [x] **Conteúdo longo:** títulos, textos extensos e endereço longo permaneceram dentro dos cartões.
- [x] **Conteúdo vazio:** a seção de notícias permaneceu organizada, sem cartões.
- [x] **Conteúdo repetido:** seis cartões ficaram alinhados e organizados no Grid.
- [x] **Navegação por teclado:** o link para pular ao conteúdo e a ordem de navegação funcionaram corretamente.

## Resultado

Todos os cinco cenários testados apresentaram o comportamento esperado.

A implementação utiliza Flexbox com quebra de linha no menu e Grid responsivo na seção de notícias.

## Critério de aceite

Nos testes realizados, o layout funcionou em 320 CSS px sem rolagem horizontal da página, mantendo a ordem semântica e a navegação por teclado.

**Status:** testes realizados com sucesso.
